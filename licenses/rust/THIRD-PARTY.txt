Rust dependencies for the Weirnote Python SDK
=============================================

These notices cover the pinned normal dependency graph on macOS, including
the build-time code that UniFFI uses to generate the Python binding. The
source archives listed below contain the unmodified crates. In particular,
the UniFFI Rust runtime and Python generator templates are available in
source form under the Mozilla Public License, version 2.0 (MPL-2.0.txt).
The wheel includes the generated Python module in source form.

The Rust standard-library notices for the release compiler are in
Rust-1.98.1-library-copyright.html.
